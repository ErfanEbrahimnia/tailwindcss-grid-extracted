Tailwind v3 · plain CSS · zero runtime

tailwindcss-grid-extracted

Precompiled flexbox and CSS Grid utility classes extracted from Tailwind CSS v3. Use familiar layout class names without installing Tailwind, configuring PostCSS, or shipping the full framework.

npm install View on GitHub

Why use this

Layout only

Flex and grid utilities compiled to plain CSS — nothing else to configure.

Zero dependencies

The published package contains only CSS files. No build step at consumption time.

Familiar names

Identical to Tailwind v3 defaults: flex, grid-cols-3, justify-between.

Modular bundles

Import everything, or just flex.css or grid.css.

Install

npm install tailwindcss-grid-extracted

Use

import "tailwindcss-grid-extracted/full.css";

<div class="grid grid-cols-3 gap-4">
  <div class="col-span-2">Main</div>
  <div class="col-span-1">Sidebar</div>
</div>
